# ✨ Luminous Prosperity

### Open Source Infrastructure for Conscious Organizations

> **"Where every person shines and the whole thrives."**

Luminous Prosperity is a comprehensive organizational development platform that transforms how enterprises understand and develop their people. Built on the integration of Integral Theory, Appreciative Inquiry, and AI-powered insights.

**This software is FREE and OPEN SOURCE because liberation shouldn't have a paywall.**

---

## 🌟 Why Open Source?

The infrastructure for conscious capitalism shouldn't be locked behind enterprise pricing. By open-sourcing Luminous Prosperity, we're distributing the weight of building a better world to everyone who wants to participate.

- **Housetrained capitalism** = ethical, conscious business
- **Non-dual holistic abundance** = everyone wins
- **A world we can all thrive in** = the mission

## 🛠️ Tech Stack

- **Frontend:** React 18 + Vite
- **Styling:** Tailwind CSS + shadcn/ui
- **Charts:** Recharts
- **Animation:** Framer Motion
- **Forms:** React Hook Form + Zod
- **Routing:** React Router v7

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/luminous-prosperity.git

# Navigate to directory
cd luminous-prosperity

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
